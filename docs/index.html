Everything you need, nothing you don't.

Monaco editor

The same editor core VS Code uses — multi-cursor, find & replace, bracket colorization, minimap, smooth everything.

Real intellisense

rust-analyzer over a built-in JSON-RPC client: completion popups and live error squiggles, wired straight into the editor.

Docked terminal

A real PTY running PowerShell, bash, or zsh — resizable, always one keystroke away (Ctrl+`).

Git built in

Stage, commit, push, pull from a dedicated source-control panel — status refreshed live, no context switching.

Language-aware build

OxIDE detects Rust, Node, Python, and Go projects and picks the right build & run commands — output streams into the dock.

Quick & themed

Fuzzy file finder (Ctrl+P), three built-in themes that restyle the whole shell, and a UI with rounded corners that respects your eyes.
